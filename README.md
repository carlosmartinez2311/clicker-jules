# Cookie Clicker Web Application

A simple, interactive, and responsive Cookie Clicker web application built with HTML, CSS, and vanilla JavaScript.

## Features

- **Interactive Cookie:** Centered SVG cookie illustration with hover and click animations.
- **Click Counter:** Tracks the total number of times the cookie has been clicked.
- **Visual Feedback:** Displays a floating `+1` animation at the click location.
- **Persistence:** Automatically saves your click count in `localStorage` so your progress is retained across browser refreshes.
- **Reset Button:** Allows you to reset the cookie counter back to zero.
- **Responsive Design:** Modern glassmorphism card UI that works seamlessly across desktop and mobile screens.

## How to Run

1. Open `index.html` in any modern web browser (e.g. Chrome, Firefox, Safari, Edge).
2. Click the cookie in the middle to start baking cookies!
